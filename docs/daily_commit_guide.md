# Daily GitHub Commit Guide — 14 Days

## Commit Message Formula
```
<type>: <what you did>

Types: feat, eda, model, analysis, deploy, docs, results, fix, chore
```

---

| Day | Task | Commit Message |
|-----|------|----------------|
| 1 | Project setup | `feat: initial project structure and dataset download` |
| 2 | EDA notebook | `eda: explore AfriSenti Amharic dataset` |
| 3 | Preprocessing | `feat: add Amharic text preprocessing pipeline` |
| 4 | Baseline model | `model: train classical ML baseline (TF-IDF + SVM)` |
| 5 | Error analysis | `analysis: baseline error analysis and findings` |
| 6 | Tokenization | `feat: add HuggingFace tokenization pipeline` |
| 7 | Fine-tuning | `model: fine-tune Afro-XLM-R on Amharic sentiment` |
| 8 | Evaluation | `results: compare baseline vs transformer performance` |
| 9 | Attention viz | `analysis: transformer error analysis and attention viz` |
| 10 | Streamlit app | `feat: add Streamlit sentiment analysis web app` |
| 11 | Deployment | `deploy: add HuggingFace Spaces deployment` |
| 12 | Model card | `docs: add model card and technical documentation` |
| 13 | Final report | `docs: add final report and polish README` |
| 14 | v1.0 release | `release: tag v1.0 — project complete` |
